📋 PRE-DEPLOYMENT CHECKLIST
═══════════════════════════════════════════════════════════════════════════

□ 1. DOWNLOAD ALL FILES
   - Download all files from this directory to your local machine
   - Keep the directory structure intact

□ 2. TRANSFER TO SCHOLAR CLUSTER
   Methods:
   a) Using SCP:
      scp -r quantum_xray/ yournetid@scholar.rcac.purdue.edu:~/
   
   b) Using FileZilla/WinSCP (GUI):
      - Host: scholar.rcac.purdue.edu
      - Upload the quantum_xray folder
   
   c) Using Scholar Data Depot (web interface):
      - Visit: https://depot.rcac.purdue.edu/

□ 3. VERIFY FILE PERMISSIONS
   ssh yournetid@scholar.rcac.purdue.edu
   cd quantum_xray
   chmod +x *.sh

□ 4. CUSTOMIZE FOR YOUR DATA
   Edit preprocess.py:
   - Set DATA_ROOT to your actual data path
   - OR leave as-is to use MedMNIST (will auto-download)
   
   Key line to change:
   DATA_ROOT = "/path/to/your/data"  # Line 17

□ 5. UPDATE EMAIL NOTIFICATIONS
   Edit submit_job.sh:
   - Change: #SBATCH --mail-user=your_email@purdue.edu
   - Line 12

□ 6. SETUP ENVIRONMENT (ONE TIME)
   ./setup_env.sh
   
   Wait ~10-15 minutes for installation

□ 7. TEST INTERACTIVELY (RECOMMENDED)
   # Request interactive GPU session
   srun -A scholar --partition=gpu --gres=gpu:1 --time=00:30:00 --pty bash
   
   # Activate environment
   module load anaconda
   source activate quantum_ml
   
   # Test data loading
   python preprocess.py
   
   # Quick training test (edit train.py first: n_epochs=2)
   python train.py
   
   # Exit when satisfied
   exit

□ 8. SUBMIT PRODUCTION JOB
   mkdir -p logs
   sbatch submit_job.sh

□ 9. MONITOR PROGRESS
   # Check job status
   squeue -u $USER
   
   # Watch output
   tail -f logs/quantum_*.out
   
   # Check for errors
   tail -f logs/quantum_*.err

□ 10. RETRIEVE RESULTS
   After training completes, download from Scholar:
   scp -r yournetid@scholar.rcac.purdue.edu:~/quantum_xray/outputs ./

⚠️  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

PROBLEM: Out of Memory (OOM)
SOLUTION: Reduce batch_size in train.py
  batch_size = 32  # or 16 if still failing

PROBLEM: Job killed (time limit)
SOLUTION: Increase time in submit_job.sh
  #SBATCH --time=48:00:00

PROBLEM: Slow data loading
SOLUTION: Increase workers in train.py
  n_workers = 16  # match your CPU count

PROBLEM: CUDA out of memory
SOLUTION: Reduce batch size and/or image size
  batch_size = 32
  img_size = 128  # instead of 224

PROBLEM: ModuleNotFoundError
SOLUTION: Ensure environment activated
  module load anaconda
  source activate quantum_ml

PROBLEM: Data not found
SOLUTION: Check DATA_ROOT in preprocess.py
  ls -la /path/to/your/data  # verify exists

PROBLEM: Permission denied
SOLUTION: Make scripts executable
  chmod +x *.sh
